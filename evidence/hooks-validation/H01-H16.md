## 3. Limitações Conhecidas do Runtime Antigravity
- **Fail-Open na Quebra do Processo do Hook:** Se o script Python terminar abruptamente antes de imprimir JSON válido na saída padrão (ex.: crash fatal do interpretador ou syntax error externo sem stderr capturado), o runtime do Antigravity trata como falha do hook e permite a continuação da ferramenta (`fail-open`). Os scripts foram construídos com tratamento global de exceção (`try/except BaseException`) para mitigar esse comportamento e sempre emitir resposta segura de bloqueio.
