# Governance & Gates
1. Dual-Track Agile: Discovery Track e Delivery Track correm em paralelo e se falam.
2. Gates de Aprovação:
   - Gate 0 (Discovery): Entendemos o problema?
   - Gate 1 (Business): Existe evidência para investir? (GO / NO-GO pelo CEO)
   - Gate 2 (Arch): A solução é tecnicamente viável?
   - Gate 3 (PR): Foi construído o que foi decidido?
   - Gate 4 (Release): É seguro, observável e sustentável?
3. Comunicação de Bloqueios: Sempre retorne no formato TYPE, FROM, TO, ISSUE, IMPACT, RECOMMENDATION (Tipos: BLOCKER, QUESTION, SCOPE_CHANGE, RISK, COST_ALERT).
